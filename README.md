<h1>VirtuaShelf</h1>
<p>This project is a small file reader that'll allow users to open .txt files, pdf files, and epub files*</p>
<p>*Currently, the EPUB files do contain some html elements in them, this will be corrected with future releases.</p>

<h2>Plans</h2>
<p>For the rest of the application, I'm planning on adding support for images, an in-app html viewer, and support for other relatively niche file types.</p>

<h3>Running</h3>
<p>For now, to run the file, simply download the code, and open the dist folder to find the executable (Sorry for not having it set up with its own releases page, I can't currently access the github site.) Currently, there is only support for windows, but linux support is coming soon.</p>
